# laborima.github.io

Matthieu Laborie's page at <https://laborima.github.io/>: projects, and Ride, the windsurf and wing foil game.

The page is developed in [chatel-apps-repository/about-matthieu](https://github.com/laborima/chatel-apps-repository/tree/master/about-matthieu). This repository only publishes it at the root of the domain (`.github/workflows/publish.yml`, deployed to the `gh-pages` branch) together with the files crawlers read at the top of the domain, in `root/`: `robots.txt` (also lists the Ocearo sitemap), `sitemap.xml` and `llms.txt`.

Changes to the page are picked up within the hour; run the workflow by hand (Actions → Publish → Run workflow) to publish at once.
